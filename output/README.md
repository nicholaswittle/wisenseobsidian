# output/ — Final Deliverables

This folder holds final deliverables — audit reports, launch checklists, completed plans, decision documents. Things you'd hand to someone else.

## How it works

1. When a task produces a final deliverable (audit report, launch checklist, completed plan), write it here
2. Link to it from the relevant project note in the vault root
3. Keep filenames descriptive: `apex-security-audit-2026-07-19.md`, `comms-link-launch-checklist.md`

This is the third stage of the Karpathy 3-folder structure: raw → wiki → output.

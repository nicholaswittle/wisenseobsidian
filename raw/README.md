# raw/ — Staging Area

This folder is the dumping ground for unprocessed research, stream of consciousness, pasted sources, and anything that hasn't been codified into a wiki note yet.

## How it works

1. Drop sources here — URLs, pasted text, research dumps, raw notes
2. Claude reads from here and writes codified wiki articles into the vault root
3. Once processed, the raw file can be archived or deleted

This is the first stage of the Karpathy 3-folder structure: raw → wiki → output.

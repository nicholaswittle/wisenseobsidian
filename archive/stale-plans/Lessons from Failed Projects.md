# Lessons from Failed Projects

> What wisense-os, my_ai, command_center, and local-agent-work-center taught us.

Related: [[Abandoned Projects — Lessons]], [[business/Business Hub]]

---

## wisense-os
- Over-engineered "operating system" concept before having a single user
- Built infrastructure instead of products
- Lesson: ship a product, not a platform

## my_ai
- Voice agent with neural command center UI — looked amazing, solved no real problem
- Spent weeks on visual polish before validating the core use case
- Lesson: pretty UI doesn't compensate for no market need
- The Claude/Deepgram/Cartesia integration was real and reusable — the app shell was not

## command_center
- Game-ified agent dispatch dashboard — fun to build, no buyer
- Built for a hypothetical user who didn't exist
- Lesson: don't build B2B tools without a B in mind

## local-agent-work-center
- Tried to build a local AI work center — too ambitious, no focus
- Lesson: one thing done well beats five things done poorly

## What we kept
- wisense_core and wisense_ui shared packages — the real reusable assets
- The governance protocol (Tripartite, MCA/MDT) — process that scales
- The vault itself — institutional memory

## The pattern
Every dead project shared the same failure: building without a customer. Apex, COMMS LINK, and New Horizon survived because they had (or have) a real user in mind. The website business has a real prospect (FFL dealer). That's the test.

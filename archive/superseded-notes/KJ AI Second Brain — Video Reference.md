# KJ AI Second Brain — Video Reference

**Source:** https://www.youtube.com/watch?v=4l8MXYUqGaA
**Topic:** Two-layered AI second brain using Claude + Obsidian

## The two-layer system

**Layer 1: Strategy + Storage (the General)**
- Claude acts as a thinking partner, not a doer
- Shares context: notes, goals, journals, calendar, reviews, projects
- Uses `Claude.md` file in the vault root as instructions
- Skills: `new project` (interviews you to create new projects), `weekly update` (interviews you, updates context across the brain)
- Value: clear goals, clear plan, clean thinking, recall any information
- Vault structure: Claude.md, goals, notes (books/videos/courses), journals, projects, reviews, skills

**Layer 2: Projects (the Soldiers)**
- Open Obsidian + Claude inside a specific project folder
- Claude is a digital employee, not a thinking partner
- `Claude.md` in the project tells Claude: what the project is, the goal, his role, what's entailed
- Each project has its own skills and commands
- Structure per project: outputs (what you want), inputs (ideas/materials), process (how Claude helps), feedback (metrics/results)

## Use cases shown

1. **Main YouTube channel** — research competitors, analyze packaging (titles, thumbnails, keywords), write body content, generate tags, sync with editor
2. **Daily YouTube channel** — Dispatch captures ideas, Claude generates titles, AI pulls thumbnail frames from video, Claude uploads/schedules
3. **One-on-one coaching** — call notes template, transcripts, Claude generates timestamps for client recordings

## Key principles (from the video)

- "The market only cares about outputs, not processes"
- "A general can't command an army from the front line" — that's why Layer 1 (strategy) is separate from Layer 2 (execution)
- Claude in Layer 1 is a thinking partner who helps decide what to do; Claude in Layer 2 is a digital employee who helps do it
- The vault gives Claude context across all projects — he's not boxed into one

## How this maps to your setup

Your vault at `C:\Users\nikwi\Notes\` is Layer 1. The governance notes, project references, and decisions are the shared context. The three launch apps (COMMS LINK, Apex, New Horizon) are Layer 2 — when you open Claude Code inside each project folder, Claude becomes the digital employee for that app.

The `claude-obsidian` plugin we just installed automates the organization that KJ does manually — it reads sources, extracts entities, cross-references, files everything, and maintains the vault.

## How to add a customer note

1. Create `customers/<Name>.md` with frontmatter + interview/feedback sections below.
2. Link it from this index table.
3. Mention durable outcomes in [[NOW]] scorecard and [[business/Experiment Log]] if it was a test.
4. Update [[hot]] only if it changes company focus.
